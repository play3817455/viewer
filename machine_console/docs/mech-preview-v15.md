# v15 机体预览相关取证

本记录限定机体预览工具所需行为：机体模型/动作、手工挂载武器，以及可手工选择的机体/武器特效资源。分析使用 `ida-pro-mcp` 加载的 `GundamOnline_CHINA_v15.exe.i64`；未据此推测服务端应发出的字段，也不把任意整数当成特效资源键。

## 已确认的机体特效资源调用

- 地图特效以外，客户端机体状态处理也会创建 `CPrjFxObject`。`sub_48A760` 的交叉引用包括 `sub_4F6190`、`sub_4F6490`、`sub_4F67C0`、`sub_4FB540` 和 `sub_493540`；这些调用位于机体状态/移动处理路径。
- `sub_48A760` 从状态记录取得一个效果资源名，最多尝试 3 组、每组左右两个变体；每个候选由两位编号改写而来。它创建 `CPrjFxObject`，设置机体当前位置和方向，并启动对象。精确字段来源、左右变体语义和两位编号规则仍待逐项核实。
- 状态处理函数 `sub_493540` 中能看到明确的本地资源路径 `fx/06/PP_06_046_03.vra` 与 `fx/09/PP_09_122_03.vra`，随后经 `sub_AB4A70` 请求对应资源。该段尚未确认创建对象的具体类，也不能泛化为所有机体的推进/射击绑定。
- `sub_AB7A40` 是地图 `fx_objects` 处理器，按效果名生成 `fx/%02d/PP_%s.vra`。它属于地图对象路径，和上面的机体状态调用分开记录，不拿它替代机体绑定分析。

## PP 特效 VRA 的可见结构

资源样本 `fx/01/PP_01_001_00.vra` 含 `Target`、`Header`、嵌套 `Plug`、`Object` 与 `Sprite`。该 Sprite 声明了 `file="fx/image/PT_01_001_00.png"`、尺寸、颜色、billboard、blend、`anim_type` 和 `anim_uv`；文件头另含帧数与循环字段。这些字段可作为预览器实现输入，不需要先猜一个武器或机体特效 ID。

v15 对象配置读取器 `sub_C508E0` 读取 `billboard_x/y/z` 并组合方向标志；`sub_C50A60` 读取 Sprite 的大小、颜色、若干开关、`anim_type` 和 `anim_uv`。因此特效预览需要按 PP 文件中的 Sprite 配置与引用图片构造，而不是把 VRA 当普通静态模型加载。`anim_type` 各枚举值和运行时 UV 推进/时间曲线还未完成逆向，当前不能宣称已有准确粒子播放。

图片对象的加载路径也已互证：`sub_C520B0` 先调用 `sub_C51F10` 建立图像/对象资源，再读取 Sprite 字段并初始化渲染资源；`sub_C51F10` 使用 `sub_C51B00` 解析输入，`sub_C51B00` 中可见 `.dds`、`.png`、`.tga` 三类扩展名和对应资源提供器分支。该链确认 PP Sprite 引用的是图像资源，但这些函数本身没有证明帧推进、透明混合或 billboard 的最终渲染行为。

## 控制台当前支持范围

- 机体 DXG/VRA 与 MRB 动作可直接加载；机体档案的挂载资源可以手工填路径、变换和骨骼，并保存。
- 机体预览本身就是空场景挂载空间；载入机体和切换 MRB 后会恢复已保存的手工模型挂载。
- 资源清单可记录数字特效 ID，也能展开显式 `fx/.../PP_*.vra` 路径的资源依赖；没有确证的 ID→PP 文件映射，不会自动代填。
- 选择 PP VRA 时，控制台解析并预览第一个可读取的 Sprite 图片，同时显示源文件中的 dims、color、billboard、blend、anim_type 和 anim_uv。点击“挂载”可将该图片作为可调位置/旋转/缩放、可选骨骼的平面加入机体空间，并写入现有 mounts 档案。该平面采用工具 alpha 混合，不声称复现客户端设置。
- 此平面显示单张 Sprite 资源图片，不播放 Header/Plug 时间轴或 UV 动画，也没有实现客户端 billboard 方向、PP 颜色乘算、实际尺寸换算和特效发射/消失逻辑。客户端精确渲染行为仍待汇编确认。

## 后续按机体预览闭环推进

1. 用客户端明确的 Sprite 构造和更新函数解出 `anim_type`、`anim_uv`、Header frame/loop 的播放语义，再实现暂停与逐帧。
2. 从 PP 实例/插件对象更新路径确认 Sprite 的尺寸换算、billboard、blend 和局部变换，之后再加入 3D 空间预览。
3. 再依据角色状态调用路径核对一个机体的推进或武器效果绑定；不根据文件名相似度自动绑定。
4. 武器仍按手工 ID/路径选模型、贴图、图标及其特效，保存每个槽位的独立记录。
